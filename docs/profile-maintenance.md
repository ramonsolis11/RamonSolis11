# Profile Maintenance

This document records the lightweight maintenance workflow used for the GitHub profile repository.

## Workflow

1. Create a focused branch from `main`.
2. Make a small, meaningful documentation change.
3. Open a pull request with a clear description.
4. Merge the pull request after verifying the change.

## Purpose

Keeping profile updates behind pull requests provides a cleaner history, makes changes easier to review, and keeps the repository aligned with standard GitHub collaboration practices.
